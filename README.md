# CatosWagon

CatosWagon adds two decorative market wagons to Valheim's Hammer menu. Use them for a roadside stall, a market square, or a camp that needs one more piece of scenery.

## Pieces

Open the Hammer and choose the **Catos Wagon** category.

- **Catos Wagon (Open)** shows the wagon with its canopy open.
- **Catos Wagon (Closed)** shows the covered version.

The pieces are decorative building objects. They do not replace a vanilla cart or add storage.

## Cost

Each wagon costs:

- 40 Wood
- 20 Fine Wood
- 8 Deer Hide

## Install

Install CatosWagon through Thunderstore, Gale, or r2modman. The package declares its BepInExPack Valheim and Jotunn dependencies, so a supported mod manager can install them with CatosWagon.

After installation, start Valheim, equip the Hammer, and look under **Catos Wagon**.

## Console prefab names

ServerDevcommands users can refer to the pieces by these prefab names:

```text
piece_catoswagon_open
piece_catoswagon_closed
```
